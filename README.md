Reading List App

About

Reading List App is a simple application that helps users manage their books and track their reading progress.

Features

- Add new books to the reading list.
- Track reading status.
- Filter books.
- Delete books.
- View summary counts of books.

Purpose

The application helps users organize their reading activities in one place.
